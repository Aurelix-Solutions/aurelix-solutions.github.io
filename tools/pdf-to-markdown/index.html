How to use it

Three steps

  1. Paste one or more PDF or DOCX links, e.g. https://arxiv.org/pdf/1706.03762.
  2. Optionally limit the pages per document, choose the OCR language for scans and set the chunk size.
  3. Click Start, then download JSON, CSV or Excel, or send the pages to your vector database, LangChain, LlamaIndex, Zapier, Make or n8n through the API.

Honest limits

What it does not do

  • Multi-column layouts (papers, forms) are read line by line across the page, so columns can interleave.
  • Tables without ruling lines are kept as text rows, not split into cells; merged cells come back as repeated or empty cells.
  • OCR quality depends on the scan; handwriting is not supported, and OCR runs at about 3 to 10 seconds a page.
  • Images, charts and formulas are not described; only their horizontal text labels come through (rotated or vertical text is skipped).
  • Files over 50 MB, password-protected PDFs, legacy .doc and other formats are skipped without charge.
  • Documents are read from the first page up to 'Max pages per document' (300 by default).
  • A document stops after 5 blank scanned pages in a row (blank pages are never charged), so scans with long blank runs end early.

FAQ

Questions buyers ask

How much does the PDF to Markdown OCR & Table Extraction cost?

$0.30 per 1,000 pages ($0.25 on paid Apify plans), billed through your Apify account; you pay only for results. Apify's free plan includes $5 of credit a month, enough for about 16,666 pages.

How does per-page pricing compare with per-PDF pricing?

You pay $0.30 per 1,000 pages ($0.25 on paid plans) plus $0.001 per run, so a 10-page PDF costs $0.003. Scanned pages cost $8 per 1,000 OCR pages instead.

Which files are supported?

PDF (any version, text or scanned) and Word DOCX. The type is detected from the file's content, so download links without a .pdf ending work. Legacy .doc, PowerPoint and Excel files are not supported.

How are scanned PDFs handled?

Each page is checked for a text layer. A page with almost no text and an image is rendered at 200 dpi and read by Tesseract OCR in the language you choose. Scans that already carry a hidden OCR text layer (common for library scans) use that layer as is.

How good is table extraction?

Tables drawn with lines are returned as Markdown tables and JSON rows. Tables laid out with spaces only, common in statistical releases, are kept as one row per line in the Markdown but are not split into cells.

What is a page for a DOCX file?

Word files have no fixed pages, so they are split on paragraph boundaries into page-equivalents of about 3,000 characters, each charged as one page.

Does it respect robots.txt?

Yes. Each download, including every redirect hop, is checked against the site's robots.txt; a robots.txt that answers with a server error counts as disallowed.

Can I use it from an AI assistant?

Yes. Give 'urls' and optionally 'maxPagesPerDocument'. It works through Apify's MCP server and API.

Is this legal?

It reads only public data any logged-out visitor can see: the documents you link (convert only documents you have the right to use). It goes at a polite pace, respects robots.txt, never logs in and never solves CAPTCHAs. It returns each page's text and tables as the document published them; copyright stays with the owner, and any personal data inside a document is your responsibility. What am I charged when a link fails?

Nothing for that link. URLs that return an HTTP error, are blocked by robots.txt, are over 50 MB or are not a PDF or DOCX produce no row and no charge. A run where every link fails costs only the $0.001 start fee, and its status message names up to 3 failed URLs with the reason.

Are blank pages charged?

No. A page with no text, even after OCR, is skipped for free and counted as an empty page in the status message. A document stops after 5 blank scanned pages in a row, so a long blank scan does not keep the run busy.

Does it retry a failed download?

No. A link that answers with an error such as HTTP 429 or 500 is reported as failed and not charged; run it again later. A host that does not answer at all is given up on after 5 seconds.

Can I convert only pages 10 to 20?

Not directly. Max pages per document reads from the first page, so set it to 20 and keep the rows where page is 10 or more. You pay for every page returned.

How are the chunks made?

Each page's Markdown is split on paragraph and then sentence boundaries into chunks of at most chunkSize characters (2,000 by default, up to 20,000), with 200 characters of overlap between chunks. Set chunkSize to 0 to get the whole page as one chunk.

In what order are documents processed?

One at a time, in the order of the urls list, and each document from its first page. The same URL listed twice is downloaded once. If the run approaches its timeout, it stops cleanly and keeps the pages already returned.

How do I know which pages were read by OCR?

The ocr field is true on those pages, and the status message gives the count. OCR pages are charged as OCR pages at $8 per 1,000 instead of the text-page price, never both.

How do I export pages to Google Sheets?

Download the run's results as CSV or Excel and open them in Google Sheets, or add Apify's Google Sheets integration to the run or a schedule so every run's results land in a sheet.
