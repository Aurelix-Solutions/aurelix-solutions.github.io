FAQ

Common questions

Do these tools need a login or cookies?

No. Every tool reads only public pages that a logged-out visitor can see, at a polite pace. None of them log in, use your cookies or solve CAPTCHAs.

How am I charged?

Per result, through your Apify account: each tool page lists its live price per 1,000 results and its start fee per run. There is no subscription, and nothing is billed for platform usage on top. Apify's free plan includes $5 of credit a month.

Can I send the results to Google Sheets, Excel or my CRM?

Yes. Download any run as CSV, Excel or JSON, or use Apify's integrations (Google Sheets, Zapier, Make, n8n, webhooks) and schedules to send results automatically.

Can an AI assistant or agent use these tools?

Yes. Each tool runs through the Apify API and the Apify MCP server, so agents such as Claude or ChatGPT with MCP support can call it and read the results.

Who builds them?

Aurelix builds, tests and maintains every tool here. Each one is checked before release against the source site, field by field, with a privacy scan that removes private individuals' details.
