How to use it

Three steps

  1. Paste your domains or website URLs, one per line, e.g. allbirds.com.
  2. Click Start; each domain takes a few seconds, ten at a time (about 40 to 60 domains a minute).
  3. Download JSON, CSV or Excel, filter by a column such as ecommerce = Shopify, or send the rows to your CRM, Google Sheets, Zapier, Make or n8n.

Honest limits

What it does not do

  • Homepage only, no JavaScript rendering: technologies loaded only by JavaScript, only on inner pages or only after cookie consent can be missed.
  • No history or first-seen dates and no technology spend estimates (BuiltWith-style history is not available).
  • SPF is read one level deep: includes are matched by name, redirects and nested includes are not followed.
  • Sites that block bots or answer with a challenge page get DNS fields only (homepage_checked is false and the note says why).
  • Detection is rule-based; a rare false match or miss is possible, and versions are not reported.
  • At most ten domains are analysed at a time, about 40 to 60 domains a minute; a homepage over 2 MB is read up to 2 MB, and a domain that takes over 45 s is skipped without charge.

FAQ

Questions buyers ask

How much does the Tech Stack API cost?

$1.50 per 1,000 domains ($1.05 on paid Apify plans), billed through your Apify account; you pay only for results. Apify's free plan includes $5 of credit a month, enough for about 3,333 domains.

How does detection work?

By matching our own rules against the homepage HTML (script URLs, page markers, the meta generator tag), the HTTP response headers and cookie names, and against the domain's MX, SPF (TXT) and NS records. A technology is listed when at least one of its rules matches.

Do you use Wappalyzer or BuiltWith data?

No. The fingerprint rules are written by us for this Actor. Wappalyzer's data is no longer open and its community forks are GPL-licensed, so none of it is copied.

Why is a technology missing?

Only the homepage is read, without running JavaScript: tools loaded later by a tag manager, only on inner pages or only after cookie consent may not appear. Tag managers themselves are detected.

How is the email provider found?

From the MX records (Google Workspace, Microsoft 365, Zoho, Proton...). When the MX points to a security gateway such as Mimecast or Proofpoint, the SPF record is used to name the provider behind it. SPF also lists email-sending services.

Does it respect robots.txt?

Always. The homepage is fetched only where robots.txt allows it, checked on every redirect hop; a robots.txt that answers a server error counts as disallowed. DNS records are public and are still read.

Can I use it from an AI assistant?

Yes. Give 'domains'. It works through Apify's MCP server and API.

Is this legal?

It reads only public data any logged-out visitor can see: the homepage of each domain you enter and its public DNS records (analyse only sites you have a legitimate reason to look at). It goes at a polite pace, respects robots.txt, never logs in and never solves CAPTCHAs. It returns the technologies a site uses and its mail and DNS providers; no personal data is extracted. To have a record removed, open an issue on this Actor's Issues tab; if a site owner formally asks us to stop, this Actor will stop. You are responsible for using the data lawfully, incl. anti-spam and privacy laws; this is not legal advice.

How are duplicates and www versions handled?

Only the host is used, lowercased, so apify.com, https://apify.com/store and APIFY.COM are one domain, analysed and charged once. www.example.com and example.com are different hosts and give two rows; for both, the MX, SPF, DMARC and NS records are read from the name without www.

Am I charged when a homepage is blocked or down?

Yes, one charge, because the row still carries the DNS fields: email provider, MX, SPF, DMARC and DNS provider. Only domains that neither resolve in DNS nor answer over HTTP, and domains with no answer within 45 s, are free. The status message counts both groups.

What do homepage_checked and note mean?

homepage_checked is true when the homepage HTML was read. When it is false, note says why, for example robots.txt disallows the page, the homepage is unreachable, or it answered HTTP 403 or 429. The technology lists then hold only what DNS shows.

Why is email_provider empty when mx is filled?

The MX hosts did not match a provider in our rules (for example a self-hosted or less common mail service), and SPF named none either. The raw mx and spf values are always returned, so you can classify them yourself.

What does dmarc_policy mean?

It is the p= value of the domain's DMARC record: none (monitor only), quarantine or reject. It is null when the domain publishes no DMARC record.

How many domains can one run take, and how fast is it?

Ten domains are analysed at a time; in our test run 49 domains took 68 s. The default run timeout is 1 hour, so for lists above about 2,500 domains raise it. Near the timeout the Actor starts no new domains and keeps the rows it has, and the status message says it stopped early.

Does it use proxies or a browser?

No. It sends plain HTTPS requests, falling back to http when https fails, with an honest bot user agent, no proxy and no browser, so JavaScript is not run. Sites that block bots still get their DNS-based fields.

Can I re-check the same list on a schedule?

Yes, with an Apify schedule or the API. Each run reads the sites live and returns a full row for every domain, so every domain is charged again. There is no change-only mode; compare the technologies column between runs to spot changes.

How do I export domains to Google Sheets?

Download the run's results as CSV or Excel and open them in Google Sheets, or add Apify's Google Sheets integration to the run or a schedule so every run's results land in a sheet.
