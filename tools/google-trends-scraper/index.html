How to use it

Three steps

  1. Type your keywords into 'Keywords', one per line (e.g. air fryer), and set the location, e.g. US (empty = worldwide), or paste Google Trends explore links into 'Google Trends URLs'.
  2. Optionally pick a time range, category, search type and region level, or add countries under 'Trending searches'.
  3. Click Start, then download JSON, CSV or Excel, or schedule it and send results to Google Sheets, Zapier, Make or n8n.

Honest limits

What it does not do

  • Google Trends values are relative (0-100), not absolute search counts; trending searches give Google's approximate volume such as 200000.
  • Related topics: Google currently returns empty topic lists to automated visitors (we tested plain requests and a real browser); the option is kept and costs nothing extra, but expect empty lists.
  • Google samples its data, so the same request can differ by a few points between runs; rising related queries vary more, since Google samples them per request and per network.
  • Keywords with very low search volume return no data; they are named in the run status and not charged.
  • On one shared scale, keywords far smaller than the largest one can round to 0; run them separately or with a smaller first keyword.
  • Large runs take time: about 2 to 3 Google requests per keyword at a polite pace; results are saved if the run nears its timeout.
  • If Google keeps refusing a comparison group after every retry, its keywords are named in the run status and not charged.
  • Google Trends URLs: only explore links are read (not Trending now or Year in Search pages), and their date must be one of the preset ranges or 'YYYY-MM-DD YYYY-MM-DD'.

FAQ

Questions buyers ask

Why do Google Trends scrapers get blocked?

Google rate-limits Trends requests hard. This Actor backs off, opens a fresh session on every rate limit and uses a residential proxy only when needed; keyword groups still blocked are named in the run status.

$1.50 per 1,000 results ($0.90 on paid Apify plans), billed through your Apify account; you pay only for results. Apify's free plan includes $5 of credit a month, enough for about 3,333 results.

What does one result include?

Everything for one keyword: the interest-over-time timeline, interest by region, top and rising related queries (and related topics when Google returns them), plus summary fields. A trending search is also one result.

Can I paste Google Trends links?

Yes. Paste explore links such as https://trends.google.com/trends/explore?q=air%20fryer,instant%20pot&geo=US&date=today%2012-m into 'Google Trends URLs'. Each link's terms, location, time range, category and search type are used for that link, and you can mix links with 'Keywords'. A link that is not a Trends explore link, or has an unsupported setting, is skipped and named in the run status; the rest of the run continues.

How are values comparable across hundreds of keywords?

Google compares at most 5 keywords at once and scales each comparison to its own peak of 100. The Actor puts your first keyword in every group of 5 and rescales each group so that keyword matches across groups, then sets the overall peak to 100. Choose a first keyword of middling popularity: a very rare one gives coarse values, a very popular one pushes small keywords to 0.

Why do my values differ from typing one keyword into Google Trends?

With 'Put all keywords on one scale' on, values are relative to every keyword in the run, not to that keyword alone. Turn it off to get each keyword on its own 0-100 scale, exactly like a single search on the Trends page. Google also samples its data, so repeated runs can differ by a few points.

Which locations and region levels work?

Any country code (US, GB, DE) or sub-region code (US-CA, CA-ON), or empty for worldwide. Region level can be country, sub-region, US metro area (DMA) or city. If Google does not offer the level you chose for that location, the Actor uses Google's default level and says so in the run status.

What are Breakout queries?

Rising related queries whose searches grew by more than 5,000% in the period. They are marked growth 'Breakout' and is_breakout true.

Does it handle Google's rate limits?

Yes. On every 'too many requests' answer it waits with exponential backoff and starts a fresh session; if the datacenter proxy keeps getting limited, the rest of the run moves to Apify's residential proxy. Results already read are kept.

Can I use it from an AI assistant?

Yes. Give 'keywords' and 'geo'; it works through Apify's MCP server and API.

What am I charged when a keyword has no data?

Nothing for that keyword. Keywords with too little search volume, comparison groups Google kept refusing, and the anchor keyword repeated in later groups are never charged. A run that returns nothing costs only the $0.0075 start fee, and its status message names the keywords that had no data.

What happens when Google blocks the run?

Each request is tried up to 8 times with growing waits and a fresh session. After 6 rate limits in a row on the datacenter proxy, the rest of the run moves to Apify's residential proxy. If 3 comparison groups in a row still end blocked, the run stops, keeps every result already read, and names the keywords it could not read.

How long does a big run take?

About 2 to 3 Google requests per keyword at a polite pace, with up to 3 comparison groups running at once. In our test 300 keywords with timelines, regions and related queries took about 12 minutes. If the run nears its timeout, it stops cleanly and keeps the results already read.

Are duplicate keywords charged twice?

No. Keywords are de-duplicated without regard to case, so air fryer and Air Fryer are read once. Keywords longer than 100 characters are skipped and named in the run status.

Can I get only trending searches?

Yes. Leave Keywords empty and add countries under Trending searches. Each trending search is one result, up to Max trending per country (1 to 1,000, in the order Google's Trending now page lists them), over the past 4, 24 or 48 hours or 7 days.

What do average_interest, peak_interest and latest_interest mean?

They summarise the timeline on the same 0-100 scale as its values: the mean over the period, the highest point (with peak_time), and the last complete point. A point for a period still running is marked is_partial in interest_over_time and is not used as the latest value.

Can I schedule it to track the same keywords every week?

Yes. Save the input as a task and add a weekly schedule. Each run reads the full time range again, so compare runs by keyword; Google samples its data, so expect a few points of difference between runs.
