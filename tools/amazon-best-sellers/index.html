How to use it

Three steps

  1. Add categories to 'Categories': a slug such as 'kitchen' or 'pet-supplies', or a Best Sellers / New Releases URL copied from any of the 10 supported Amazon sites.
  2. Pick the marketplace for slugs (amazon.com by default), and optionally New Releases, the number of pages (50 ranks each), or 'Only new entries'.
  3. Click Start, or schedule it daily to track rank moves. Download JSON, CSV or Excel, or send results to Google Sheets, Zapier, Make or n8n.

Honest limits

What it does not do

  • 10 Amazon marketplaces (.com, .co.uk, .de, .fr, .it, .es, .ca, .com.au, .in, .co.jp); Movers & Shakers and Most Wished For are not supported (Amazon serves them empty to logged-out visitors).
  • Up to 100 ranks per list, Amazon's own maximum.
  • Amazon sometimes repeats a product at two ranks while the list updates; the repeat is dropped, so a list can return 98 or 99 products.
  • Some products show no price on the list; price is then empty.
  • Lists change through the day; a run is a snapshot of when it ran.
  • If Amazon starts answering with robot checks midway, the products already read are kept and the run status says 'Partial'.

FAQ

Questions buyers ask

Can I scrape Amazon Best Sellers in other countries?

Yes: 10 marketplaces, amazon.com, .co.uk, .de, .fr, .it, .es, .ca, .com.au, .in and .co.jp, with the currency code on every price.

Is there a cheaper alternative to Junglee's Amazon Best Sellers scraper?

Yes. This Actor adds rank change and new entries against your last run. The other two cover Movers & Shakers and Most Wished For, and amazon-scraper/amazon-bestsellers-scraper covers 18 marketplaces against 10 here.

How much does the Amazon New Releases & Best Sellers cost?

$0.55 per 1,000 products ($0.38 on paid Apify plans), billed through your Apify account; you pay only for results. Apify's free plan includes $5 of credit a month, enough for about 9,090 products.

Which Amazon sites are supported?

Ten: amazon.com, .co.uk, .de, .fr, .it, .es, .ca, .com.au, .in and .co.jp. Pick one in 'Amazon marketplace' for slugs, or paste a list URL from any of them; a run can mix marketplaces. Prices come exactly as Amazon shows them, with the code in 'currency': usually the marketplace's own currency, but amazon.co.uk and .de can show US dollars to Apify's US-based proxy (seen in our cloud tests).

Does it cover Movers & Shakers or Most Wished For?

No. Amazon serves those lists empty to logged-out visitors on all 10 marketplaces, so they are rejected rather than returned blank. Schedule a Best Sellers list daily instead: rank_change and new_entry show what moved.

How do I find a category slug?

Open the category's Best Sellers page on your Amazon site (e.g. amazon.de/gp/bestsellers); the slug is the part after /bestsellers/, e.g. 'kitchen'. For a subcategory, paste the whole URL.

What are rank_change and new_entry?

They compare with your previous run of the same list: rank_change = previous rank minus current rank (positive means it climbed), new_entry = it was not on the list last time. On the first run previous_rank and rank_change are empty and new_entry is false.

Why is price empty for some products?

Amazon does not show a price on the list for every product (for example when it is only sold through other offers). We never guess a price.

Does it need a proxy?

Apify Proxy is used and the default datacenter group works; nothing extra to buy.

Is this legal?

It reads only public data any logged-out visitor can see: Amazon Best Sellers pages. It goes at a polite pace, never logs in and never solves or clicks through CAPTCHAs or check pages (when Amazon shows its 'Continue shopping' check page, the Actor treats it as a block, drops that proxy session and retries on a fresh one). It returns product listing fields only (rank, title, price, rating, review count, links); no review text or reviewer data. To have a record removed, open an issue on this Actor's Issues tab; if Amazon formally asks us to stop, this Actor will stop. You are responsible for using the data lawfully, incl. anti-spam and privacy laws; this is not legal advice.

What am I charged for an unknown category or an empty run?

Each run pays the $0.001 start fee, and then only for products saved to the dataset. An unknown category, an unsupported URL, or an 'Only new entries' run with nothing new returns 0 products and costs only the start fee; unknown and unsupported entries are named in the run status. If Amazon blocks a list midway, the products already read are kept and charged, and the status starts with 'Partial'.

Which URL formats work?

Best Sellers and New Releases list URLs from the 10 supported marketplaces: /gp/bestsellers/..., /gp/new-releases/..., and the /zgbs/ and /zgnr/ forms such as amazon.com/Best-Sellers-Electronics/zgbs/electronics. The www. prefix is optional, and ref= tags and query strings are removed. A bare slug like 'kitchen' is read from the marketplace and list chosen in the input.

Can it crawl all subcategories of a category?

No. Each entry in 'Categories' is one list. To cover subcategories, paste each subcategory's Best Sellers URL; every row then carries its own category_name and category_url.

How does rank tracking remember the previous run?

It keeps one memory per list URL and tracking name, holding each product's rank from the last run of that list. Every run replaces it, so rank_change always compares with the run just before. A run stopped by your maximum charge limit does not update the memory. Use a different 'Tracking name' to track the same list separately, e.g. per client.

Why did a page return fewer than 50 ranks?

Amazon renders the first 30 products of a page and loads ranks 31 to 50 with a second request, which the Actor makes too. If that second request fails, the page keeps what it has and the status says how many pages returned fewer than 50 ranks.

What are price, price_max and reviews_count?

price is the number Amazon shows on the list, in the marketplace's own number format, and price_text is the text as printed.

How fast is it?

In our test runs, one list of 100 ranks took about 20 seconds, and 8 lists (800 products) took 99 seconds. The Actor pauses about 2 seconds between requests.
