At a glance

What the Google Autocomplete API does

Sources
Google Search and YouTube autocomplete
Modifiers
A-Z and 0-9, question words, prepositions and comparisons (EN, ES, FR, DE, PT, IT)
Markets
Any country (gl) x language (hl) grid, up to 20 combinations per run
Output
13 fields per keyword with intent tags; JSON, CSV, Excel, API
Automate
Schedules, webhooks, Zapier, Make, n8n, Google Sheets, MCP for AI agents

Who it is for

  • SEO writers building topic clusters and FAQ sections from real question searches
  • YouTube creators finding video titles people actually type
  • PPC managers collecting commercial and local long-tail phrases per country
  • AI agents that need keyword ideas for a brief through MCP

Output

What you get

  • keyword: the suggested phrase as shown, with seed, source (google or youtube), country and language
  • modifier and query: what was added to the seed and the exact text sent
  • position: rank in the suggestion box (1 = top); depth: 1 from the seed, 2 from a suggestion
  • intents: question, commercial, local, comparison (empty = other); word_count
  • source_url and scraped_at (ISO 8601 UTC)

How to use it

Three steps

  1. Enter one or more seed keywords, e.g. 'coffee maker', and pick Google, YouTube or both.
  2. Optionally set countries and languages (e.g. us, gb with en), the modifiers, depth 2 for a long-tail tree, and Max keywords.
  3. Click Start, then download JSON, CSV or Excel, or send the keywords to Google Sheets, Zapier, Make or n8n through the API.

Honest limits

What it does not do

  • Phrases that contain a phone number or an email address are dropped and not charged.
  • No search volume, CPC or difficulty: autocomplete gives phrases and their order only.
  • The suggestion box this Actor reads returns at most 10 suggestions per query (Chrome's address bar can show up to 15 from a different Google client, which is not used), so the yield per seed is bounded by the number of modifiers (about 60 queries per seed, source and market at depth 1).
  • Suggestions change over time and Google personalises them by location; the country setting localises them, but results from a datacenter IP can differ slightly from what a signed-in user sees.
  • Intent tags come from word rules, not a model; rare phrasings can be missed or mis-tagged.
  • At most 20 country x language combinations per run, and depth at most 2.
  • Speed: about 1 to 3 requests a second through the proxy, roughly 400 to 1,000 keywords a minute; a seed with every modifier on two sources takes about a minute.
  • Google can throttle datacenter IPs; the run then stops early with the keywords collected so far.

FAQ

Questions buyers ask

How much does the Google Autocomplete API cost?

$0.45 per 1,000 keywords ($0.35 on paid Apify plans), billed through your Apify account; you pay only for results. Apify's free plan includes $5 of credit a month, enough for about 11,111 keywords.

Where do the keywords come from?

From the public autocomplete endpoint that powers the Google Search and YouTube search boxes (suggestqueries.google.com). Each keyword is a suggestion Google returned for the seed or a seed plus modifier.

Does it give search volume?

No. Search volume needs Google Ads Keyword Planner (a login) or a paid data vendor, both outside this tool. Autocomplete order is a rough popularity signal: position 1 is shown first.

What do the intent tags mean?

Simple word rules: question (starts with how, what, why, can, is...), commercial (best, buy, price, cheap, review, deal...), local (near me, nearby, open now...), comparison (vs, versus, or, alternative, better than...). A keyword can carry several tags or none.

Which languages get question and preposition modifiers?

English, Spanish, French, German, Portuguese and Italian. Other languages get the seed and the A-Z/0-9 modifiers.

What happens if Google slows the requests down?

Each request is retried with backoff and a fresh proxy session. If Google keeps refusing, the run stops early, keeps every keyword collected so far, ends SUCCEEDED and says so in the status message.

Can I use it from an AI assistant?

Yes. Give 'keywords' and optionally 'sources', 'countries' and 'languages'. It works through Apify's MCP server and API.

Is this legal?

It reads only public data any logged-out visitor can see: the autocomplete suggestions Google shows in its search boxes. It goes at a polite pace, checks robots.txt, never logs in and never solves CAPTCHAs. It returns suggested search phrases with their source, market and rank; no personal data is extracted. To have a record removed, open an issue on this Actor's Issues tab; if Google formally asks us to stop, this Actor will stop. You are responsible for using the data lawfully, incl. anti-spam and privacy laws; this is not legal advice.

What am I charged for a seed with no suggestions?

Only one request is made for it: when the plain seed gets no suggestions, its modifiers are skipped, so a run of nonsense seeds costs only the $0.0005 start fee. The status message counts the seed, source and market combinations that had no suggestions.

How does the de-duplication work?

A phrase is kept once per source, country and language, comparing it without case and extra spaces. The same phrase found from another modifier, another seed or at depth 2 in the same market is skipped and not charged. The same phrase in another market or the other source is a separate row.

How many keywords does one seed give?

Usually 300 to 600 unique phrases per source and market with every modifier on. In our test coffee maker gave about 945 keywords over Google and YouTube in the US. Each query returns at most 10 suggestions, so the modifiers set the ceiling.

How long does a run take?

Requests go out at up to 4 a second with up to 4 in flight. One seed on Google and YouTube with every modifier took 40 to 56 seconds in our tests. Depth 2 and more markets multiply the requests, so expect several minutes.

What happens when Google is down or throttles the run?

If the suggest service does not answer at the start, the run ends at once with nothing queried or charged. During a run, failed requests are retried with backoff on a fresh proxy session; after 8 failures in a row the run stops early, keeps every keyword collected so far and says so in the status message.

What do modifier, query and position mean?

modifier is what was added to the seed (a letter, a number, a question word or a preposition; empty for the seed alone), query is the exact text sent to the suggestion box, and position is the phrase's rank in that box, 1 being the top.

Which countries and languages work?

Any two-letter country code and any interface language code Google accepts, such as us, gb or de and en, fr or pt-BR. Every country is combined with every language, up to 20 combinations per run. Question and preposition modifiers exist in English, Spanish, French, German, Portuguese and Italian.

How do I export keywords to Google Sheets?

Download the run's results as CSV or Excel and open them in Google Sheets, or add Apify's Google Sheets integration to the run or a schedule so every run's results land in a sheet.
